## Local preview and UI verification

The site remains plain HTML, CSS, and JavaScript, with no build step or runtime dependencies. From the parent directory, run `python -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173/saad-hayat/`. All assets use relative URLs to preserve the GitHub Pages repository base path.

The visual system uses self-hosted Manrope, warm ivory, ink, and gold. Project images are actual public demo captures; provenance and the My Doc Sage sign-in limitation are documented in [assets/projects/README.md](assets/projects/README.md).

Basic source checks: `node --check script.js` and `git diff --check`. No build or lint scripts were configured in the original repository. Browser verification artifacts, screenshots, and temporary verification dependencies live in the ignored `.artifacts/` directory and are not part of the deployed site.
